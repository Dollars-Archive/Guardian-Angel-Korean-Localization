## 게임 소개

**Guardian Angel (ガーディアンエンジェル / 가디언 엔젤)**은 2003년 PlayStation 2로 발매된 **시간축·다중시점 SF 미스터리 어드벤처 게임**입니다.

전직 형사 출신 사립탐정 **에릭 딜라이트**는 정체불명의 조직이 연루된 사건에 휘말린 뒤 육체를 잃고 영체가 됩니다.  
인간 세계로 돌아온 그는 딸 **에스텔**과 주변 인물들이 비극적인 사건으로 향하고 있음을 알게 되고,  
직접 몸으로 개입하는 대신 여러 인물의 시점과 서로 다른 시간대를 오가며 정보를 모아 사람들에게 **‘영감’**을 전달합니다.

플레이어는 하나의 큰 사건 속에서 서로 얽혀 있는 **6개의 스토리**를 넘나들며,  
실패한 미래나 배드엔드에서 얻은 정보까지 과거를 바꾸는 단서로 활용해 사건의 진상에 접근하게 됩니다.

### 작품 특징

- 일반적인 선택지형 ADV보다 `Inspire Bullet`을 수집하고 적절한 인물에게 사용해 행동을 바꾸는 **I.B.S. 시스템**이 핵심입니다.
- `Synchro`를 통해 등장인물의 내면을 읽고, 같은 사건을 다른 관점에서 재해석할 수 있습니다.
- 배드엔드나 실패한 시간대에서 얻은 정보가 단순한 게임오버 기록이 아니라 **다음 진행을 위한 단서**로 활용됩니다.
- 하나의 큰 이야기와 서로 얽힌 **6개의 스토리, 여러 시간대**를 왕복하면서 흩어진 정보를 조립해 나갑니다.
- 다중시점이 단순한 연출에 그치지 않고 게임 시스템과 직접 연결되며, 다른 시점에서 과거 장면의 의미가 달라지는 **복선 회수 구조**가 강점입니다.
- 겉보기에는 미소녀 ADV의 인상이 강하지만, 실제로는 연애보다 **사건 해결, 정보 차이, 시간축을 이용한 추리**의 비중이 높은 작품입니다.

보다 자세한 작품 소개와 발굴 자료는 **[Dollars Archive 게임 소개 페이지](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/game.html?file=platforms%2Fps2%2Fgames%2Fguardian-angel.md)**에서 확인할 수 있습니다.
